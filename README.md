📚 Repositório de Exercícios TypeScript (TS)
Este repositório é dedicado à prática, exploração e domínio da linguagem TypeScript, focando em conceitos fundamentais, estruturas de dados, tipagem avançada e integração com ambientes de teste (Jest) e ambientes de execução (Node.js).

🎯 Objetivo
O principal objetivo é consolidar o aprendizado de TypeScript, garantindo que o código seja robusto, escalável e bem tipado. Cada exercício visa resolver um problema específico, desde a manipulação de coleções até a tipagem correta de funções assíncronas.

⭐️ Principais Conceitos Abordados
Abaixo estão alguns dos tópicos explorados nos exercícios deste repositório:

Tipagem Básica e Inferência: Uso de tipos primitivos (string, number, boolean).

Unions e Intersections: Combinação de tipos.

Arrays e Tuplas: Tipagem de coleções ordenadas.

Generics (<T>): Criação de funções e classes reutilizáveis.

Interfaces e Types: Definição da forma de objetos.

Enums: Conjuntos de constantes nomeadas.

Módulos: Configuração de imports/exports em ambiente ESM (nodenext).

Programação Orientada a Objetos (POO): Classes, herança e modificadores de acesso.
